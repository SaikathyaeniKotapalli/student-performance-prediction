
# Student Performance Prediction

## About the Project
This is a beginner machine-learning project that predicts a sample student's result using study hours, attendance, and previous marks.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Decision Tree Classifier
- GitHub

## How It Works
1. Loads sample data from a CSV file.
2. Splits the data into training and testing sets.
3. Trains a Decision Tree model.
4. Evaluates the model accuracy.
5. Predicts a result for new student inputs.

## How to Run
Install Python, then run:

pip install -r requirements.txt

python main.py

## Important Note
This is an educational demonstration using a small sample dataset. Its predictions are not validated for real-world student assessment.

## Project Type
Independent personal learning project.
